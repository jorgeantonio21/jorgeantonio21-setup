# Nushell

Default configuration files for [Nushell](https://www.nushell.sh/) v0.110. These are the generated defaults kept here for reference. Minimal customization.

## Prerequisites

- [Nushell](https://www.nushell.sh/) installed

## What's included

| File        | Description                          |
|-------------|--------------------------------------|
| `config.nu` | Main Nushell configuration (defaults) |
| `env.nu`    | Environment variable configuration    |

## Manual install

```sh
cd nushell
chmod +x install.sh
./install.sh
```

This symlinks the config files to `~/.config/nushell/`.
